# Current Options

## Text Field

- Enter a Title: Share this with your friends
- Exclude: Exclude by Page ID, Page Title or Page Slug

## Toggles

### Advanced Options

- Google Social analytics: Be sure you have google analytics already in page
- Auto hide button: Auto hide button on page load when used on left or right side.
- Use port on the url: Ex. ssl port :443
- No follow social link: This will make all social link nofollow.

### Where to show buttons

- Show on Left Side
- Show on Right Side
- Show Before Post
- Show After Post

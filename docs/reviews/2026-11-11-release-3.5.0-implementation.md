## Implemented scope

- Opt-in Native share action, default off, in settings, shortcodes, blocks,
  widgets, Elementor and WPBakery. Excluded from profile links and URL templates.
- Native API call uses the resolved context title/URL and runs during the user
  gesture. Browser URL mode preserves its existing eligibility and hook rules.
- One pending native call per document, quiet cancellation, explicit error
  feedback and Copy link fallback. Native plus Copy yields one unsupported/no-JS
  fallback per group. Clipboard fallback restores focus.
- Native icon assets across all six bundled sets and supported shapes; generated
  button CSS loaded only when native sharing renders. Existing historical CSS
  and the shared appearance stylesheet are byte-identical to the baseline.
- Pinterest complex image query regression, strict native opt-in parsing,
  conditional asset and profile exclusion contracts.
- Production PHP 7.0 syntax retained; syntax matrix expanded to PHP 8.2/8.4 and
  real WordPress execution on PHP 8.4/8.5 includes regular, AJAX and multisite.
- Build tooling refreshed to `@wordpress/scripts` 37.1.0 and `adm-zip` 0.6.1.
  Canonical release builds use the frozen pnpm lock. High-severity audit failures
  now block CI; development tools are excluded from the plugin ZIP.
- Version metadata aligned to 3.5.0; translations and release instructions updated.
- After publication, the release workflow downloads the versioned WordPress.org
  ZIP, installs it on fresh WordPress, checks file hashes against the reviewed
  candidate, runs E_ALL, Plugin Check and the six-project browser suite.

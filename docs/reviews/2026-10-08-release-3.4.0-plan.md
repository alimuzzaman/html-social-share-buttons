# Release 3.4.0 plan: Copy Link, WhatsApp, and Reddit

Status: approved working plan for the next public release. It does not
authorize tagging or WordPress.org publication; those remain the owner's
manual steps in [`RELEASE-PROCESS.md`](../RELEASE-PROCESS.md).

## Review of the current state (2026-10-08)

- 3.3.0 is published on WordPress.org (2026-09-21) and matches `master`
  (`cd25944`). The tag-validation and manual-publication workflow runs were
  green. WordPress.org reports `Tested up to: 7.1.3`, which is the current
  core release, so no compatibility bump is needed.
- The WordPress.org support forum has no open threads; the GitHub mirror has
  one 2017 issue (Open Graph meta), which stays out of scope because SEO
  plugins own `<head>` metadata.
- The working tree only contained a stale development build under `build/`
  (source maps and unminified bundles). A production `pnpm run build`
  reproduced the committed bytes exactly, so there was no unreleased work.
- Development dependencies are current enough; `@wordpress/scripts` 36 is a
  major jump and is deferred to a separate maintenance change so the release
  diff stays feature-only.
- [`TODO.md`](../../TODO.md) and the 2026-09-20 research recommend one small
  user-facing feature next: Copy Link, or one or two modern networks. 3.3.0
  delivered the URL contract, the frontend-feature catalog, the shared `JS`
  badge, and the local browser-URL runtime that those features depend on.

## Outcome

Ship 3.4.0 with three additive, off-by-default share actions that reuse the
3.3.0 pipeline without changing existing output:

1. **WhatsApp** share link (`whatsapp`).
2. **Reddit** share link (`reddit`).
3. **Copy link** action (`copy`): a real anchor to the resolved page URL with
   an opt-in local clipboard enhancement, a visible and screen-reader
   confirmation, and a no-JavaScript fallback.

Existing sites see no change until they enable a new action. Default
settings, stored options, templates, hooks, markup, and assets for the seven
existing networks stay byte-identical.

## Non-goals

Mastodon (needs an instance decision), Threads, share counts, link
shortening, hosted SDKs, analytics, native Web Share, tracking-parameter
cleanup, a global URL mode, and dependency major upgrades.

## Decisions

| Topic | Decision |
| --- | --- |
| IDs and CSS classes | `whatsapp`, `reddit`, `copy`; labels WhatsApp, Reddit, Copy link |
| Defaults | All three disabled for new and existing installs |
| WhatsApp template | `https://wa.me/?text=%%title%%%20%%permalink%%` (official universal link; `%20` survives `esc_url()`) |
| Reddit template | `https://www.reddit.com/submit?url=%%permalink%%&title=%%title%%` |
| Copy link target | The resolved permalink, raw (not query-encoded). Explicit custom URLs and loop posts keep their existing resolution; browser-URL mode updates it with the raw address |
| Copy link markup | `<a class='copy' href='…' data-hssb-copy-link='1' rel='…' aria-label='Copy link'>`; no `target`, so the no-JS fallback is a real link users can copy from the context menu |
| Copy link runtime | `build/copy-link.js`: delegated click, plain left-click only, `navigator.clipboard` then `execCommand('copy')` then `window.prompt`; shared polite live region; temporary `is-copied` class with CSS-only "Copied" feedback |
| Frontend JS catalog | New entry `copy_link` (`setting: icons.copy`). The asset collector enqueues one script per collected feature. Browser URL and Copy link each load only when an eligible anchor was rendered |
| Admin surfaces | Copy link shows the shared `JS` badge in Settings, has no share-template editor and no profile-link field; block, Elementor, and WPBakery controls carry the same warning text |
| Profile links | WhatsApp and Reddit accept profile links like other networks; `copy` is never a profile link |
| Icons | Bootstrap Solid and Tabler Outline use pinned upstream glyphs (`whatsapp`, `reddit`, `link-45deg`; `brand-whatsapp`, `brand-reddit`, `link`) with recorded SHA-256 checksums. The four historical packs get generated SVG tiles from the MIT Bootstrap glyphs through a new deterministic generator with a `--check` mode, matching the existing pack wrappers |
| Colors | WhatsApp `#25D366`, Reddit `#FF4500`, Copy link `#4B5563` |
| Version | 3.4.0 in the plugin header, readme stable tag, `PluginConfig::VERSION`, both `block.json` files, and the collector default |

## Work breakdown and file ownership

### A. Network registration (PHP, JS, fixtures)

- `BuiltInNetworkProvider`, `Network` (optional `kind` for the copy action),
  `BuildShareButtons`, `HookedShareUrlResolver`, `ResolveShareUrl`
- `SettingsDefaults`, `OptionSettingsRequestMapper` owned network keys,
  `SettingsRequestSanitizer` (reject `copy` profile links)
- Labels: `IconSetPayloadBuilder`, `BlockRegistrar`, `BuilderLabels`
- `LegacyApiRegistrar` defaults, `src/js/blocks/shared/networks.js`,
  `src/js/admin/settings/app.js` template keys
- Fixtures: `settings-schema-baseline.json`, `frontend-output-baseline.json`
  only if a scenario changes
- Tests: `NetworkRegistryTest`, `SettingsSchemaTest`,
  `ShareUrlResolutionContractTest` (decoded parameters for both new
  templates), `tests/share-template-contract.php`

### B. Icon assets

- `scripts/iconsets/upstream/*` new pinned glyphs and checksums
- `scripts/generate-iconsets.js` (colors and file maps) and the generated
  `assets/iconsets/{bootstrap-solid,tabler-outline}` tiles and stylesheets
- New `scripts/generate-legacy-network-assets.js` producing
  `iconset/{default,flat,long_shadow,prajin}/{square,circle}/{whatsapp,reddit,copy}.svg`
- `resources/iconsets/*.php` manifests, `ASSET-SOURCES.md`,
  `THIRD-PARTY-NOTICES.txt`, `docs/ICON-COVERAGE-MATRIX.md`
- Tests: `IconSetRegistryTest`, `CanonicalIconAssetTest`,
  `tests/e2e/browser-matrix/iconsets.spec.js`, icon rows in
  `tests/share-template-contract.php`

### C. Copy link feature

- `FrontendFeatureRegistry` (`copy_link`), `RenderFacade` feature reporting,
  `HtmlRenderer` copy anchor, `AssetCollector` per-feature scripts,
  `PluginConfig`/`PluginFactory` script URLs
- `src/js/copy-link.js`, `package.json` build entries,
  `tests/js-build-boundary-contract.php`, `browser-url.js` raw-slot support
- `assets/frontend/button-appearance.css` copied-state feedback
- Admin: `settings-renderer.js` badge and no-template panel for `copy`,
  profile-link filter, `SettingsPayloadBuilder` strings
- Builders: block inspector help, Elementor and WPBakery control descriptions
- Tests: `tests/copy-link-smoke.js`, `tests/frontend-feature-contract.php`,
  `CanonicalFrontendAssetCollectorTest`, `BrowserUrlDescriptorTest`,
  renderer parity

### D. Release metadata and docs

- Version bumps listed above; `readme.txt` description, FAQ, and changelog;
  `changelog.txt`; `README.md`; `design/wordpress-org/LISTING-COPY.md`;
  `TODO.md`; translations via `pnpm run i18n:build`

## Execution order

1. A and B in parallel (disjoint files), then `pnpm run icons:check`,
   `settings:check`, and PHPUnit in the Sandbox.
2. C on top of A, then the JS smoke tests, PHPUnit, and the Playwright
   settings and iconset specs where the Sandbox allows.
3. D, then `pnpm run zip` and `release:check` to prove the archive builds.
4. Commit on `master` in reviewable steps; no tag.

## Acceptance gates

- `pnpm run icons:check`, the new legacy generator `--check`, and
  `pnpm run settings:check` pass.
- PHPUnit (regular, AJAX, multisite contract) passes in the Sandbox.
- Default-settings frontend output is unchanged (golden master green).
- With only existing networks enabled, no frontend script is enqueued.
- With `copy` enabled: exactly one `hssb-copy-link` script, the anchor is a
  real link to the resolved URL, and clipboard success and failure paths are
  covered by the smoke test.
- With browser URL and `copy` enabled on an eligible page, the copied value
  is the raw browser address and other networks still receive the encoded
  component.
- WhatsApp and Reddit decoded query parameters equal the raw permalink and
  title, including Unicode, ampersands, and existing query strings.
- Release metadata, archive, and plugin-check contracts pass.

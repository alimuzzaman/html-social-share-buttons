# Current Options Reference

This document lists all available configuration options for the HTML Social Share Buttons plugin, organized by tab and category.

## General Tab

### Display Settings
- **Show on Front Page**: Toggle to display buttons on the home/front page
- **Show on Posts**: Toggle to display buttons on individual posts
- **Show on Pages**: Toggle to display buttons on pages
- **Show on Archives**: Toggle to display buttons on archive pages
- **Default Style**: Select default button style (default/outline/rounded/square)
- **Default Size**: Select default button size (small/medium/large)

## Networks Tab

### Network Configuration
- **Enabled Networks**: Array of enabled social network IDs
- **Network Order**: Array defining the display order of networks
- **Custom Networks**: Array of user-defined custom networks

### Individual Network Settings
- **Facebook**: Enable/disable Facebook sharing
- **Twitter**: Enable/disable Twitter sharing
- **LinkedIn**: Enable/disable LinkedIn sharing
- **Pinterest**: Enable/disable Pinterest sharing
- **Reddit**: Enable/disable Reddit sharing
- **WhatsApp**: Enable/disable WhatsApp sharing
- **Google Plus**: Enable/disable Google Plus sharing (legacy)
- **Google Bookmarks**: Enable/disable Google Bookmarks
- **Email**: Enable/disable email sharing

## Profiles Tab

### Profile Management
- **Profiles**: Array of button profiles with custom network configurations
- **Default Profile**: Select which profile to use by default

### Profile Configuration
- **Profile Name**: Custom name for the profile
- **Network Settings**: Per-network enable/disable and custom labels
- **Display Settings**: Style, size, text labels, icon-only mode

## Integrations Tab

### BetterLinks Integration
- **BetterLinks Enabled**: Toggle BetterLinks integration
- **BetterLinks API Key**: API key for BetterLinks service

### Page Builder Integrations
- **Elementor Enabled**: Toggle Elementor page builder integration
- **Divi Enabled**: Toggle Divi page builder integration
- **Beaver Builder Enabled**: Toggle Beaver Builder integration

## Appearance Tab

### Button Appearance
- **Title**: Custom title text for share buttons
- **Icon Style**: Select icon style (default/outline/rounded/square)
- **Button Size**: Select button size (small/medium/large)
- **Button Spacing**: Number value for spacing between buttons
- **Custom CSS**: Custom CSS code for button styling

## Placement Tab

### Position Settings
- **Auto Placement**: Toggle automatic button placement
- **Placement Position**: Select position (before/after/both/left/right)
- **Placement Post Types**: Array of post types where buttons should appear
- **Exclude Pages**: Comma-separated list of page IDs/titles/slugs to exclude

## Advanced Tab

### Analytics & Tracking
- **Google Analytics**: Toggle Google Analytics integration
- **Auto Hide Buttons**: Toggle auto-hiding buttons on page load
- **Use Port in URL**: Toggle including port numbers in share URLs
- **No Follow Links**: Toggle adding nofollow attribute to share links

### Performance
- **Cache Enabled**: Toggle response caching
- **Cache Duration**: Number of seconds to cache responses
- **Debug Mode**: Toggle debug logging and error display

## Shortcode Tab

### Shortcode Generation
- Dynamic shortcode generation based on current settings
- Custom parameter support for individual button configurations

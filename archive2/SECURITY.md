# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in HTML Social Share Buttons, please follow the responsible disclosure process outlined below:

1. **Do not publicly disclose the vulnerability** until it has been reviewed and patched.
2. **Contact the maintainers directly** at:
   - Email: [security@htmlsocialshare.com](mailto:security@htmlsocialshare.com)
   - Or open a private security advisory via GitHub (if available).
3. Please include:
   - A detailed description of the vulnerability
   - Steps to reproduce
   - Any relevant logs, screenshots, or proof-of-concept code

## Vulnerability Handling Process

- We will acknowledge receipt of your report within 2 business days.
- The team will investigate and work to reproduce the issue.
- If confirmed, we will prioritize a fix and coordinate a release.
- You will be credited in the release notes unless you request otherwise.

## Supported Versions

| Version | Supported          |
| ------- | ----------------- |
| latest  | :white_check_mark:|

Older versions may not receive security updates.

## Disclosure Policy

- Please give us a reasonable time to address the issue before any public disclosure.
- We are committed to transparent and responsible handling of all security reports.

Thank you for helping keep HTML Social Share Buttons and its users safe!
